# eru documentation

Documentation is organised using the [Diataxis](https://diataxis.fr/) framework, which splits docs into four
categories based on what the reader is trying to do:

| Section | Answers | Use when you want to... |
|---|---|---|
| [**Tutorials**](tutorials/README.md) | *Can you teach me?* | Learn eru by following a guided, hands-on lesson |
| [**How-to guides**](how-to/README.md) | *How do I do X?* | Accomplish a specific task you already understand |
| [**Reference**](reference/README.md) | *What are the details?* | Look up exact commands, flags, formats, and behaviour |
| [**Explanation**](explanation/README.md) | *Why does it work this way?* | Understand the concepts and design behind eru |

If you're new to eru, start with the [Getting started tutorial](tutorials/getting-started.md).
